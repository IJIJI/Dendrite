`@dendrite-lang/core` is the language; `editor` and `link` are optional. This page will be the complete setup for a host: install, a language, an environment, a runtime with the host's contract as a port layer, and the options each of those takes. The user-facing getting started is under Learn; this one is for the developer who embeds the language.
