The standard library is a language: primitive types, the ops every host has, and the operators that are sugar over them. The reference beside this page is generated from the language itself, so it cannot drift. This page will explain the categories and the conventions the ops share - variadic inputs, `any`, higher-order ops with a function-typed input.
